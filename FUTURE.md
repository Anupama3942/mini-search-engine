# Future Roadmap

The following features and improvements are ideas for future development and are **not currently implemented**.

## Scalability & Architecture
- Elasticsearch/OpenSearch integration for distributed indexing
- Large-scale corpus support (100K+ documents)
- Distributed architecture (sharding, replication)
- Real-time indexing pipeline

## Advanced Ranking & Machine Learning
- Larger embedding models (sentence-transformers, 384-dim+)
- BERT/transformer-based reranking
- Advanced LTR (LambdaMART, neural LTR)
- Click-through learning (online LTR from user feedback)

## Query & Search Capabilities
- Personalization and user profiles
- Multilingual search and Unicode tokenization
- Query auto-completion with n-gram language models

## Infrastructure & Performance
- Search result caching with TTL
- Frontend JavaScript SPA (React/Vue)
- WebSocket real-time search

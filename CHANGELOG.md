# Changelog

All notable changes to the Mini Search Engine project are documented here.

## [v9.0.0] - Stage 21
- Final capstone release
- Polish and extensive documentation
- Portfolio release readiness

## [v8.0.0] - Stage 20
- A/B experimentation framework
- CTR (Click-Through Rate) tracking
- Statistical analysis of experiments

## [v7.0.0] - Stage 17
- Query understanding improvements
- Spell correction implementation
- Intent classification

## [v6.0.0] - Stage 15-16
- Semantic search capabilities
- Hybrid retrieval implementation
- Production architecture setup
- Docker containerization

## [v5.0.0] - Stage 13-14
- BM25 ranking algorithm
- Learning-to-Rank (LTR) pipeline

## [v4.0.0] - Stage 10-12
- Analytics and tracking
- Performance optimization
- Quality evaluation framework

## [v3.0.0] - Stage 7-9
- Boolean search support
- Phrase search capabilities
- Fuzzy matching and typo tolerance

## [v2.0.0] - Stage 4-6
- TF-IDF ranking implementation
- Web interface development

## [v1.0.0] - Stage 1-3
- Basic search functionality
- Inverted index construction
- Core text processing and tokenization
